# Zero-Bloat Sound

Открытый кроссплатформенный аудио/видео-плеер в духе Winamp — дух, а не косплей:
простота, скины и функционал без раздувания. Каждая фича выключается в настройках.

**Статус: pre-release, активная разработка.** Играет, индексирует, показывает клипы,
носит скины — но до v1.0 ещё дорога.

## Что уже умеет

- **Плейбек**: BASS-движок, gapless/кроссфейд, мягкая пауза, скорость с сохранением тона,
  A-B повтор, умный шаффл, CUE-листы, резюме длинных файлов, ReplayGain, медиа-клавиши, трей
- **Медиатека**: SQLite, инкрементальный скан, живой поиск, обложки (теги → папка →
  Cover Art Archive), рейтинги, дубликаты, сканер битых, все форматы плейлистов
- **Видео (libmpv)**: клипы в общем плейлисте с музыкой; свернул окно — картинка
  не декодится, звук продолжается
- **Интерфейс**: режимы под сценарий — список / «сейчас играет» / компакт
  (авто-сжатие окна до винамп-мини) / настройки; EQ 10 полос, визуализатор,
  waveform-сикбар, магнитное окно
- **Скины**: классические Winamp `.wsz` и свой формат `.zbs` (+конвертер)

## Сборка

```
dotnet build ZeroBloatSound.sln
dotnet test ZeroBloatSound.sln
```

.NET 8, Avalonia. Нативные библиотеки BASS лежат в `lib/bass` и копируются сборкой.
Для видео нужен libmpv — см. [lib/mpv/README.md](lib/mpv/README.md) (без него плеер
работает, видео недоступно).

## Структура

```
src/Core       — плейбек, бэкенды (BASS, mpv), настройки
src/Library    — медиатека (SQLite, теги, обложки)
src/Skins      — движок скинов (.wsz / .zbs)
src/UI.Desktop — Avalonia-интерфейс
tests/         — модульные тесты
```
